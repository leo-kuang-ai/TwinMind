# 10_当前工作台

## 用途
承载正在推进的目标、项目、决定、风险和下一步。

## 放什么
项目首页、待决策事项、周期计划与复盘、启动契约。

## 不放什么
不堆原始材料，不保存已经结束且无需继续关注的项目副本，不把系统定时任务定义混入普通项目待办。

## 最小动作
开始任务先打开对应项目首页，确认目标、状态、最大风险和下一步。

## 高价值任务默认出口
重大任务收尾时默认留"最小结果回放"：用 [[90_模板/高价值知识学习与回放模板]] 的 keep / revise / stop 字段记录结论，回放页放本区或项目目录，修订结论回流对应知识页。模板分工：《决策模板》记决策本身，《交付复盘模板》复盘交付过程，《高价值知识学习与回放模板》承载回放结论——不新建重复模板。
