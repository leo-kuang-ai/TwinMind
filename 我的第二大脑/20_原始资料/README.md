# 20_原始资料

## 用途
保存可追溯的原件、来源与必要快照。

## 放什么
文章原文、会议记录、报告、截图、附件及来源信息。

## 不放什么
不把个人结论混入原文，不用摘要覆盖原件，不静默改写历史证据。

## 来源包结构

一批外部材料按"来源包"归档，一个包对应一个子目录：

```text
<日期-主题>/
  README.md        # 来源信息（作者、发布时间、获取时间、完整性）
  original.*       # 原始文件本体（保留原格式）
  attachments/     # 图片等附件（有才建）
  SHA256SUMS       # 包内全部文件的校验和清单
```

- 只为实际存在的对象建目录：没有附件就不建 `attachments/`；
- 外部导出的压缩包先逐文件解包核对再入库，登记来源页的校验和字段；
- 同一内容只存一份：重复获取时回链既有来源包，不复制第二份。

## 最小动作
保存来源、时点和完整性；形成结论时链接到 `30_知识主题/`。摄取节奏与轻重分档见 [[30_知识主题/来源登记与摄取分档]]。
