# 数字分身成熟度路线

> 原则：数字分身不是一次性搭出来的系统，是逐阶段长出来的能力。每一阶段只在前一阶段的退出判据达成后才进入——跳级的分身是空壳：有画像没有治理会信口开河，有检索没有记忆则每次都从零认识你。

## 总览

| 阶段 | 一句话 | 核心新增件 | 退出判据 |
| --- | --- | --- | --- |
| L1 结构基座 | 文件不再散落 | 九区目录 + Git 基线 + 启动契约 | [[99_维护记录/七天冷启动与三十天验收清单\|七天冷启动]] 信号达成 |
| L2 治理库 | 说的都可回溯 | 协议三档 + 证据分级 + 巡检/体检/周报三步卡 | 三十天验收通过，维护在预算内 |
| L3 可检索库 | 找得到沉睡的知识 | 按升级门禁接入语义检索（TwinMind 仓库随附可选配件 `ai-search-kit/`） | 评测基线建立，漏召回持续下降 |
| L4 数字分身 | 越用越像你 | 数字分身画像 + 记忆系统 + 每日进化闭环 | 分身通过"分身三问"（见下） |

## L1 结构基座

- **进入信号**：文件散落在聊天记录、下载目录和多个笔记工具里，重复找不到。
- **要做的**：九区骨架、Git baseline、填写 [[10_当前工作台/00_第二大脑启动契约|启动契约]]（三个真实问题、维护预算、停止条件）。
- **反熵**：不要在此阶段加插件和自动化；唯一纪律是 00_待处理 不积压。

## L2 治理库

- **进入信号**：库里开始出现"同一事实两个版本""AI 转述当成原文"这类真实失败。
- **要做的**：AI 协作协议生效（三档权限 + 证据四级 + 冲突/覆盖登记）；每周 30 分钟三步卡（巡检 → 体检 → 周报）；[[30_知识主题/到期巡检与到期处置|到期巡检]]。
- **退出判据**：连续四周，任何一条结论都能在 30 秒内回答"依据是什么、什么时候核对过"。

## L3 可检索库

- **进入信号**：准确关键词仍稳定漏召回，且已在维护日志登记了真实漏召回样本（这是 [[30_知识主题/工具选择与升级门禁|升级门禁]] 的硬前提）。
- **要做的**：接入本地语义检索（TwinMind 仓库随附 `ai-search-kit/`，含编排、增量补丁与评测门禁；从其他途径获取本 Demo 的，按工具清单自选同类方案）；**先建 golden set 评测基线，再接内容**——换模型、调阈值、升级组件前后各跑一次，回归超阈值不合入。
- **退出判据**：评测基线（Recall@5 / MRR 或同类指标）建立并有留档；新问题的"找不到"频率可观察地下降。

## L4 数字分身

- **进入信号**：L1-L3 已稳，且你发现每次换会话都要重新向 AI 解释"我是谁、我怎么做事、上次这类问题怎么决策的"。
- **要做的**：
  1. 填写 [[10_当前工作台/00_数字分身画像|数字分身画像]]（身份事实唯一事实源、决策风格、盲点与提醒义务）；
  2. 启用 [[99_维护记录/记忆系统/README|记忆系统]]（会话收尾契约 + 记忆条目提升五检）；
  3. 让 [[60_任务系统/10_任务定义/每日进化|每日进化]] 从 `draft` 转 `pilot`，经验候选持续产出；
  4. 把 [[30_知识主题/从可信记忆到决策学习系统|决策学习]] 的三环进化跑起来：知识 → 决策 → 结果回看。
- **退出判据——分身三问**（任换一个新会话，不加载画像与记忆时答不上、加载后答得对）：
  1. "你是谁的分身？他/她现在的关键口径是什么？"
  2. "他/她的已知盲点有哪些？这次建议里命中了吗？"
  3. "上次同类问题我们怎么决策的、结果如何回看？"
- **反熵**：画像与记忆是活页不是档案——季度复核一次，失效就按覆盖决策登记更新；连续两季未复用的记忆条目退役。

## 三条主线的关系

结构决定能积累什么（L1-L2），检索决定能召回什么（L3），人格与记忆决定像不像你（L4）。工具与组件会过时，这套分层与门禁可以原样搬进任何新工具。方法论文档见 [[30_知识主题/第二大脑建设与运行方法论|第二大脑建设与运行方法论]]。
