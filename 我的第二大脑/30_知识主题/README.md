# 30_知识主题

## 用途
保存围绕长期问题形成的稳定认知、框架和方法。

## 放什么
能独立回答一个问题，并包含结论、证据、边界和来源的知识页。

## 不放什么
不放未分流材料，不把一次感想或 AI 总结直接写成当前事实。

## 最小动作
新知识先设为 `candidate`；真实使用和核验后再决定是否提升。

## 当前示例
- [[第二大脑完整工具清单]]：回答“有哪些可选工具”，不要求全部安装；
- [[工具选择与升级门禁]]：回答“什么时候才值得增加工具”；
- [[七阶学习闭环]]：回答“如何把看过的知识转化为能使用的能力”；
- [[从可信记忆到决策学习系统]]：回答“如何用真实结果推动知识和判断持续进化”。
