# 七阶学习闭环

> 状态：`pilot`。这是一套把“看过”转化为“会用”的工作性框架，不是固定流水线，也不是已经证实适用于所有领域的认知定律。

## 一句话定义

学习不是把资料放进知识库，而是让一个知识单元逐步变成**可提取、可解释、可调用、可拆解、可取舍、可重构、可迭代**的能力。

```text
记忆 → 理解 → 应用 → 分析 → 判断 → 创新
  ↑                                  ↓
  └──────── 反思、校准并重启 ────────┘
```

七阶是诊断工具，不是只能向上的阶梯。应用失败可以退回理解，预测落空可以退回分析，跨场景失效可以退回判断。

## 七阶执行卡

### 1. 记忆：从眼熟到能提取

目标不是背下全文，而是记住关键模型、触发条件、判断边界和查证时机。

- 把知识压缩成一个结构、一个场景和三个关键词；
- 合上材料，凭记忆还原核心关系，再对照补缺；
- 在 24 小时和 7 天后做一次无提示回忆。

通过信号：不看材料也能说出核心结构、最容易混淆的一点，以及需要回查原文的地方。

### 2. 理解：从会复述到能解释

- 用不依赖原术语的方式解释“它实际如何起作用”；
- 给出正例、反例和关键条件变化后的预测；
- 明确区分“理解机制”和“记住定义”。

通过信号：不了解主题的人也能复述你的解释，你还能指出解释尚未覆盖的部分。

### 3. 应用：从跟着做到独立解决新题

- 关闭答案、示例和笔记，解决一个不同于原例的新问题；
- 先写方案和理由，再看参考或运行结果；
- 记录失败属于遗忘、误解、条件识别错误还是执行失误。

通过信号：能在至少一个真实新场景中独立调用知识，并根据反馈修正下一次行动。

### 4. 分析：从列因素到拆出可检验关系

- 写出“条件 → 机制 → 结果”；
- 区分现象、原因、机制和结果；
- 为主解释提出一个替代解释，以及能够区分两者的证据。

通过信号：关键关系都能回答“为什么相连、如何验证、何时失效”。

### 5. 判断：从哪个好到何时选哪个

- 在目标、约束、收益、代价和风险下比较候选方案；
- 写清每个方案适合什么、不适合什么；
- 明确当前选择，以及什么新证据会让结论翻转。

通过信号：他人能够复现你的判断路径，而不是只看到结论。

### 6. 创新：从换个说法到产生新用途

- 把模型迁移到另一个领域，标出对应关系和失配边界；
- 改变一个核心假设或约束，重新构造方案；
- 用新模型处理一个原框架未直接覆盖的真实问题。

通过信号：新组合改变了至少一个解释、预测或行动选择，并接受真实案例或小实验检验。

### 7. 反思：从总结感受到修改学习方法

- 找出本轮最有价值的成功、最大错误和最意外反馈；
- 判断错误发生在哪一阶；
- 只修改一条学习规则，并为下一轮设置可观察的验证点。

通过信号：形成一条具体的“停止 / 开始 / 保留”，下一轮能够检查它是否减少同类错误。

## 按失败信号选择动作

| 失败信号 | 优先退回 |
|---|---|
| 找不到、想不起来 | 记忆：重建提取线索 |
| 能复述但解释不了 | 理解：补机制、例子与预测 |
| 能解释但不会解决新题 | 应用：做无提示迁移 |
| 结果与预测不一致 | 分析：重查因果与替代解释 |
| 换一个场景就失效 | 判断：收窄适用边界 |
| 旧模型解释不了新现象 | 创新：重组模型或提出新假设 |
| 同类错误反复发生 | 反思：修改判断规则或隐藏假设 |

## 使用门禁

- **原始资料**：只需要保存原件、来源、时点并保证可检索；不要强制跑七阶。
- **普通知识**：先做到理解、边界和一次使用；足以支持当前任务就停止加工。
- **高价值能力或重大判断**：完成分析、判断、反证和真实结果回看，必要时再运行完整七阶。
- **创新性主张**：真实验证前保持 `candidate` 或 `inferred`，不能因为表达生动就升级为事实。
- **AI 的角色**：可以生成练习、反例和压力测试，但不能同时充当假设提出者、答案生成者、结果裁判和能力认证者。

## 最小实践方式

选择本周必须使用的一项知识，复制 [[90_模板/高价值知识学习与回放模板]]。先完成与当前失败有关的阶梯，再把它放进真实任务；不要为了填满模板延迟行动。

一个月内至少完成三次真实使用后，再判断这套方法是否值得保留、收缩或停止。验收看迁移成功、重复错误是否减少和维护成本，不看笔记长度。

## 证据边界

本页综合主动回忆、通俗解释、无提示迁移、因果分析、方案比较、实验和复盘等常见学习实践。七阶的组合方式及默认节奏是待验证的操作框架，不代替具体领域的能力标准；时间、次数和通过线都应根据任务风险与真实反馈调整。
