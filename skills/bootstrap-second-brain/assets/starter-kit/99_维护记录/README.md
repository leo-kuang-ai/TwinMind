# 99_维护记录

## 用途
记录系统如何变化，让交付、故障、恢复和规则调整可追溯。

## 放什么
会话交付记录、维护日志、恢复演练、巡检结果和决策回放。

## 不放什么
不作为业务事实或稳定知识的默认来源，不保存无价值的完整聊天逐字稿。

## 最小动作
每次实质交付记录目标、交付物、验证证据、未决风险和最多 3 条 Candidate。

## 运行指南
- 建设路线与知识进化：[[99_维护记录/定时任务与知识进化]]；
- 七天冷启动与三十天验收：[[99_维护记录/七天冷启动与三十天验收清单]]；
- 每月检查与季度治理：[[99_维护记录/每月检查与季度反熵清单]]。

第一版先手工执行，连续稳定两周后再考虑自动提醒。
