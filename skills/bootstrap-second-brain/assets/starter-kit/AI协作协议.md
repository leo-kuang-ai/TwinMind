# AI 协作协议

<!-- TWINMIND_MANAGED_START:ai-collaboration-policy -->

## 永不执行
1. 不删除、覆盖或用摘要替代原始资料；
2. 不把未验证内容、搜索结果或 AI 生成内容写成事实；
3. 不擅自对外发布、发送、承诺或上传敏感内容；
4. 不静默修改当前权威结论、核心权限和历史记录；
5. 不读取当前任务无权访问的目录和数据。

## 必须确认
1. 对外发布终稿；
2. 删除、批量移动、历史改写和不可逆操作；
3. 核心目录、字段、权限和协议变更；
4. 人员、组织、客户和其他敏感判断；
5. Candidate 晋升为长期规则或当前权威知识。

## 可以自主执行
1. 只读搜索、统计、诊断、来源回查；
2. 新建草稿、Candidate、检查清单和修改建议；
3. 在不覆盖原件的前提下补充链接、来源和最小元数据；
4. 更新当前项目状态、索引、维护日志和交付记录；
5. 生成可审阅 diff，并在批准范围内执行可恢复修改。

## 输出要求
结论先行；标注来源、时点和口径；区分 verified / inferred / unverified；说明风险、反例、未知和下一步；所有修改可追溯、可预览、可回滚。
