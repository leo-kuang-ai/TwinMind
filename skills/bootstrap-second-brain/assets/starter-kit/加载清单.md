# 加载清单

## always_load
- `AI协作协议.md`

> 常驻预算提示：always_load 只保留协议一页；新增治理规则（证据分级、冲突登记、覆盖决策登记）已并入协议正文，不新增常驻文件。扩充常驻内容前先评估加载负载。

## 按任务加载
- 当前项目：先读 `10_当前工作台/` 对应项目首页；
- 执行或审核运行任务：先读 `60_任务系统/` 对应任务定义，再只读其声明的输入路径和最近运行记录；
- 研究与判断：再读相关 `30_知识主题/`，重要事实回查 `20_原始资料/`；
- 写作与交付：读取对应项目、知识、来源和 `40_输出成果/` 草稿；
- 复盘与追溯：读取 `99_维护记录/` 相关会话和日志；
- 每周体检与周报：读 `99_维护记录/每周知识体检清单.md` 与 `90_模板/周报模板.md`，到期清单由 `30_知识主题/到期巡检与到期处置.md` 的只读方式产出；
- 摄取新来源：先读 `30_知识主题/来源登记与摄取分档.md` 判断轻重档位。

## 默认排除
- `00_待处理/` 不进入正式结论；
- `draft / paused / retired` 任务不作为已启用调度加载；
- `rejected / superseded / archived` 只在审核历史时读取；
- 密钥、缓存、索引和未授权数据不进入 AI 上下文。
