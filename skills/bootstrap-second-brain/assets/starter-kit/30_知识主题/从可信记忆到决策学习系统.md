# 从可信记忆到决策学习系统

> 原则：第二大脑的进化不等于文件、字段、插件和自动化越来越多，而是同类问题解决得更快、更可信，并且能够根据真实结果修正知识与判断规则。

## 下一阶段的核心问题

当知识库已经能保存、追溯和检索信息后，继续扩大摄取量通常不是最重要的升级。更值得追问的是：

> 系统能否在真实任务中发现知识模型与现实结果的偏差，并让下一次同类判断减少错误？

核心公式：

```text
第二大脑进化 = 可信知识 × 真实任务 × 结果反馈 × 模型修订
```

任何一项长期为零，进化都会停留在文档或叙事层。

## 成熟度参考

| 阶段 | 能力 | 下一步重点 |
|---|---|---|
| G0 信息仓库 | 能保存文件 | 建立目录职责和原件边界 |
| G1 可信记忆 | 可追溯、可检索、能处理冲突 | 让知识进入真实任务 |
| G2 认知伙伴 | 能解释、分析、比较并生成方案 | 记录假设、裁决和结果 |
| G3 决策学习系统 | 能用结果校准判断，减少重复错误 | 提高跨场景迁移与回放密度 |
| G4 受控元学习 | 能发现哪种思考方式有效并修改规则 | 保持人类裁决和证据门禁 |
| G5 高自主数字分身 | 能预测需求并受控执行 | 只有前序证据充分后才评估 |

这不是行业统一标准，也不是必须追求的等级。达到当前真实需求所需的阶段后，应优先稳定运行。

## 三环进化模型

```text
知识学习环：知识 → 理解 → 模型 → 边界
                         ↓
真实任务环：问题 → 判断 → 行动 → 结果 → 偏差
                                     ↓
系统进化环：偏差 → 补证 / 反证 → 保留 / 修订 / 降级 / 淘汰
                                     ↓
                              回到下一轮学习
```

三环各有职责：

- **知识学习环**生成可使用的模型；
- **真实任务环**用行动结果检验模型；
- **系统进化环**决定知识、能力或规则如何保留、修订或退出。

[[七阶学习闭环]]只作为认知诊断器，不新增七个目录、七种文件状态或七套自动化。

## 最小进化单元

真正的进化单元不是一篇写得完整的文档，而是：

```text
一个模型
+ 一个适用场景
+ 一条行动规则
+ 一次真实结果
+ 一次偏差解释
```

例如，“重点事项需要明确检查机制”只是一条观点。成为可进化知识后，还需要回答：

- 什么场景适用，什么时候过度检查会造成副作用；
- 本次采取了什么行动，预期结果是什么；
- 实际发生了什么，证据在哪里；
- 偏差来自模型、条件判断、执行还是外部变化；
- 下次应该保留、收窄、修订还是放弃这条规则。

## 先激活现有闭环，不新增一层系统

常见误区是发现使用不足后，马上增加仪表盘、每日问题、母题索引或自动化。更稳妥的顺序是复用已有入口：

```text
真实问题 / 待决策事项
        ↓ 先查知识库中的历史经验与证据
建议与备选方案
        ↓
人类裁决 → 行动 / Owner / 回看日期
        ↓
结果证据与决策回放
        ↓
周复盘：结果 · 决断 · 杠杆 · Stop / Start
        ↓
修订知识、模板、Skill 或下一次行动
```

只有现有入口在真实运行中反复失败，且失败原因能够复现，才增加新的结构或能力。新机制必须替换或压缩旧步骤，不能另拿一份维护预算。

## 30 天最小验证

不修改顶层目录，不新增 schema。选择三个高价值知识对象，例如一个业务判断、一个协作方法和一个技术能力；每个对象至少进入两个不同场景。

每次只记录六件事：

1. 目标任务；
2. 当前模型与关键假设；
3. 采取的行动；
4. 实际结果与证据；
5. 偏差及替代解释；
6. 应保留、收窄、修订或废弃什么。

### 值得继续的信号

- 出现真实任务样本，而不是只新增知识页；
- 至少一项知识完成第二场景迁移；
- 至少修正一条高置信但错误或边界过宽的判断；
- 同类错误在下一轮没有原样发生；
- 有知识被主动降级、拒绝或收窄，而不是所有内容都“验证成功”；
- 维护成本仍在 [[10_当前工作台/00_第二大脑启动契约]] 的预算内。

### 应当停止或收缩的信号

- 文件和字段增加，但没有真实行动与结果；
- 练习、答案、评价和认证都由 AI 自己生成；
- 复盘永远只有“继续加强、持续优化”；
- 新机制与现有项目、决策或复盘重复记录；
- 维护闭环挤占了真正要完成的工作。

## 人与 AI 的边界

AI 可以帮助查找证据、构造反例、比较方案、识别可能的偏差并提出 Candidate。真实行动结果、重大取舍、知识晋升、规则变更和对外承诺仍由人类确认。

检索命中率、摘要质量或模型自评只能证明局部能力，不能代替真实任务成效。没有结果证据时，应诚实保留为 `candidate`、`monitoring` 或 `pilot`。
